# Default Aegis portrait

The default is `webapp/public/aegis-avatar-v2.jpg`, served locally at
`/ui/aegis-avatar-v2.jpg`. It is a fictional humanoid secretary portrait generated
with the built-in `image_gen` tool on 2026-09-28. The generated image was encoded
as JPEG at quality 90 for delivery (about 233 KiB), without changing its composition.
No external avatar host, model call or account is needed to display it.

Both former built-in paths (`/aegis-avatar.svg` and `/ui/aegis-avatar.svg`) map to
this new default. Uploaded or individually generated portraits are preserved.
The owner can choose a different portrait or restore the default in Settings.
The existing emblem remains available as a brand asset; it is no longer the
assistant's default face.
