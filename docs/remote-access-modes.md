# 本机部署与手机访问模式

日期：2026-09-27。
状态：已实现 portable 部署助手和 Passkey；自动化验证与真实外网验收分开记录。安装步骤见 [REMOTE_ACCESS.md](REMOTE_ACCESS.md)。

## 产品选择

Aegis 默认运行在用户自己的电脑上，数据库保存在本机。项目不运营用户账号、
公共网关或托管服务。部署时让用户选择访问方式，不默认开启公网入口：

| 选项 | 用户体验 | 网络边界 |
|---|---|---|
| 仅本机使用 | 安装后直接在电脑上使用；可以稍后开启手机访问 | 仅监听本机回环地址 |
| 私网远程访问（推荐） | 电脑和手机安装、登录 Tailscale；手机连接其 VPN 后打开浏览器 | Tailscale Serve + HTTPS，仅允许符合私网访问规则的设备连接 |
| 公网远程访问（可选） | 电脑运行 Tailscale；手机只需浏览器，无需 VPN | Tailscale Funnel + HTTPS，公网请求可以到达 Aegis |

两种远程模式均使用 Passkey 登录，并保留应用层鉴权。首次安装与
以后切换模式都应显示实际访问范围。无人值守安装未指定模式时保持仅本机，
不能替用户选择公网模式。电脑需要开机、联网并运行 Aegis；休眠期间无法远程访问。

Tailscale 自身提供私网 VPN 连接，不需要再购买另一项 VPN 服务。
私网模式是否影响用户原有 VPN，需要在目标手机系统上验证并在安装向导说明。
域名、证书和常规配置由安装程序或部署 agent 协助完成；账号登录、设备授权
与 Passkey 注册仍需要用户操作。无需让普通用户购买或理解域名。

## 公网启用提示

展示以下提示，并让用户主动确认；确认框不预选：

> **公网访问的风险高于私网访问**
>
> 开启后，互联网上的任何人都可以向你的 Aegis 登录入口发送请求。
> HTTPS 和 Passkey 提供传输与登录保护，但不能消除软件漏洞、设备被入侵
> 或错误配置带来的风险。相比私网模式，你的实例会面临更多扫描和攻击尝试。
>
> 请保护账号和设备、及时安装安全更新、妥善保存恢复凭据，
> 并承担选择公网部署后的日常安全管理责任。不需要公网访问时，请关闭它。
> 如果你不确定如何选择，建议使用私网模式。

确认文案：**我已了解公网访问风险，并选择开启公网访问。**

提供「返回选择私网」与「确认开启公网」两个操作。普通安装的通用 `--yes`
不能替代该确认；自动化入口必须有独立、明确的公网风险确认参数，并由部署
agent 向用户展示上述说明后取得选择。确认不能绕过安全检查。

这段提示说明部署者的管理责任，不替代项目自身的认证、权限控制、安全修复
与准确的风险说明，也不能据此宣称公网部署已安全。

## 启用前必须完成的保护

- 未绑定时远程入口只允许使用本机签发的配对凭据注册；不能让第一个公网访客注册成为机主。
  配对凭据短时有效、单次使用，并由本机已授权操作发起。
- 两种模式都保留 HTTPS、Passkey、会话撤销与恢复流程。数据库密钥留在服务端，
  不放入手机访问链接、二维码、浏览器存储或配对凭据。
- 保护所有敏感页面、API、流式连接和文件下载；落实请求来源、CSRF、会话与
  必要的频率限制。不能只保护首页。Passkey 登录不替代工具执行的授权边界。
- Aegis 后端继续绑定回环地址，只由指定代理转发。代理连接来自回环地址不代表
  访客是本机机主；公网不能借代理调用本机引导登录或绕过身份认证。
- 私网部署者应配置最小访问权限，仅开放指定用户／设备访问 Aegis 所需端口。
  检查实际规则，不假定新建 Tailscale 网络默认禁止设备互通，也不覆盖用户
  已有的无关网络策略。
- 从公网切换到私网或仅本机时，撤销原有公网入口并验证结果。不能仅修改界面标签。
  停用失败时明确报错，不能报告已经私有。部署失败不能自动降级为无认证公网服务。
- 公网风险确认只记录非敏感的选择与提示版本，不记录密钥或配对令牌。

## 当前缺口与验收

Passkey 登录由 `core/src/remote_access.rs` 和 `/access` 提供；旧 Google MFA
设置接口中的 `webauthn_available=false` 仅指旧的 step-up 注册流程尚未迁移，
不能用来判断新机主登录能力。模型 provider 登录仍是另一套凭据。

已实现主机配对、第二凭据、恢复、撤销、来源校验、挑战单次消费和有界请求频率；
部署助手检查实际 Serve/Funnel 配置，拒绝覆盖不属于它的转发规则。
测试使用真实 WebAuthn 验证和虚拟认证器、真实加密数据库与进程监督器，
仅模拟 Tailscale CLI。没有安装或登录 Tailscale、开放真实远程入口。

仍需外部环境验收：

1. 真机验收：手机蜂窝网络访问、私网未连接时拒绝、未登录与越权请求拒绝、
   流式聊天、断线重连、电脑重启、关闭公网后无法再从公网访问。
2. 验证 Linux／WSL2 的主机与代理连接方式，以及目标手机的 VPN 兼容性；
   安装脚本现状不能当作原生 Windows 已支持的证据。

3. 实际 tailnet 访问规则、设备授权过期与重新认证。助手不修改已有 ACL。
4. `/opt` systemd 部署的接线；当前助手只管理 portable 本地监督器。

通过以上验证之前，不宣传为已完成真机验收的一键安全远程部署。

## 外部服务边界

截至本次核实，Tailscale Personal 提供免费个人方案，Funnel 包含在所有方案中；
Funnel 仍标记为 Beta，并有不可自行调整的带宽限制。可用性与政策由第三方决定。
Funnel 中继转发加密流量，TLS 在用户电脑上的 Tailscale 进程终止；
这不改变 Aegis 向所选模型服务发送请求的事实。
